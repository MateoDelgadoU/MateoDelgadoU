# Mateo Delgado

I'm a freelance software developer based in San Nicolás de los Arroyos, Argentina. My work centers on the backend of web applications. At Recobro, I designed the PostgreSQL data model for a debt recovery platform, built its API with NestJS, and implemented role-based access in the Next.js dashboard. I also use Python and FastAPI for client projects and automation.

I hold a degree in programming from Universidad Tecnológica Nacional, Facultad Regional San Nicolás, where I'm currently studying systems engineering.

## Selected projects

- [Devter](https://devter.space/) is a workspace I built for developers to organize project notes and save frequently used commands. It uses Next.js and MongoDB.
- [MatSa Software](https://www.matsasoftware.site/) is the bilingual site for our two-person software studio. We build custom applications and integrations.
- [Standard Model](https://github.com/MateoDelgadoU/Standard-Model) is an interactive guide to elementary particles, built with React and TypeScript. Readers can explore quarks, leptons, and bosons in the [live visualization](https://standard-model.vercel.app/).
- [Doctor Tangalanga Oficial](https://tangalangaoficial.com.ar/) is an archive I built in contact with the comedian's family. Visitors can search his calls by transcript and browse photographs from the family collection.
